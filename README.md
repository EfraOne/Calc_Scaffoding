# Калькулятор лесов 3D

Расчёт комплекта строительных лесов с трёхмерной схемой, составом, массой и стоимостью.

- **Рамные** (ЛРСП 20 / 30 / 40 / 60 / 100)
- **Хомутовые** (ЛСПХ 40 / 60 / 100)
- **Радиусные** (ЛСПХ 40 / 60 / 100)

Цены с НДС по прайсу от 17.08.2026. Масса ориентировочная.

Это один статический файл `index.html` без сборки и зависимостей (кроме шрифтов Google Fonts). Его можно открыть локально двойным щелчком или опубликовать через GitHub Pages.
